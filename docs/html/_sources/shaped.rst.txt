Spans, shapes, sequences, ...
=============================

Your computer loves predictable and compact data layouts, and so should you. Packing spherical
harmonic and Zernike expansion coefficients efficiently typically leads to cumbersome indexing
schemes which are hard to work with. For this reason, zest provides a system of abstraction for
indexing arbitrary multidimensional data that is easy to use, efficient, flexible, and extensible.
