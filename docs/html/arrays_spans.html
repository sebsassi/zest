Arrays and spans¶

Along with the shape system which enables the creation of complex multidimensional index sets, zest offers the means of using these to construct both owning multi-dimensional arrays as well as non-owning views to such arrays.

Types¶

template<typename ElementType, typename ShapeType, typename Allocator = std::allocator<ElementType>>
class ShapedArray¶

A container for contiguous multidimensional data.

This class allows for definition of containers of contiguous multidimensional data of arbitrary shape. It generalizes the concept of tensor and multidimensional arrays to datasets whose indices don’t necessarily form a rectangular grid.

Template Parameters:

  • ElementType – Type of elements of the view.

  • ShapeType – Type defining the multidimensional shape of the data.

  • Allocator – Allocator type for the internal buffer.

A non-owning view of contiguous multidimensional data.

This class allows for definition of non-owning views of contiguous multidimensional data of arbitrary shape. It generalizes the concept of tensor and multidimensional array views to datasets whose indices don’t necessarily form a rectangular grid.

  • ShapeType – Type defining the multidimensional shape of the data.
