Shapes¶

Shapes are the means with which zest maps complex indexing schemes efficiently to contiquous ranges of memory.

Consider, as a prototypical case, the spherical harmonics, which are indexed by the two indices \((l, m)\) with \(|m| \leq l\). Conventionally, if \(l < L\) for some math:L, these would be stored in an array of size L times 2L, and simply accessed like regular array elements. However, this uses two times more memory than necessary (the array has \(2L^2\) elements when we only need \(L^2\) of them), and some indices are very far from each other (the elements corresponding to \((0, 0)\) and \((1, 0)\) have \(2L - 1\) unused slots between them).

It would be more efficient if all elements were stored with no wasted space in between. This can be done by mapping \((l, m)\) to \(l(l + 1) + m\), for example. This way \((0, 0)\) is followed immediately by \((1, -1)\), and so on.

Shapes are zest’s way of managing such complex mappings, such that the user only ever needs to worry about the indices, while the underlying mapping to elements in memory is done by the shape machinery.

Types¶

class NullShape¶

Type which communicates that an object has no underlying shape.

The null shape communicates that a given object has no underlying shape. It is primarily used in subshape hierarchies to indicate that we have reached the bottom of the hierarchy. All shapes of rank \(N\) should have it as its \(N\)th subshape.

template<typename SequenceType>
class SequencedShape¶

Shape which is generated by an infinite sequence.

Some shapes can be naturally regarded as being generated by an infinite sequence of index tuples, such that they can be fully specified by a single number. An example of such a sequence is the sequence of index pairs \((l, m)\) with \(|m| \leq l\), which can be naturally mapped to a contiquous sequence via \(l(l + 1) + m\), such that only the cutoff for the index \(l\) needs to be know to get a finite shape.

Concretely, the shape is described by a single number, the order, such that the index of its outermost dimension is less than the order.

All subshapes of sequenced shapes are, by definition, also sequenced shapes.

Template Parameters:

SequenceType – Type of generating sequence.

template<std::size_t... extent_params>
class TensorShape¶

Shape describing the layout of a general multidimensional array.

This class describes the shape of multidimensional arrays/tensors. It allows tensor shapes may be known at compile time (static) or may only be known at runtime (dynamic). Thus any of the extent_params having the value std::dynamic_extent corresponds to a dynamic dimension, while any other value corresponds to a static dimension of the given size.

Template Parameters:

extent_params – Parameters describing the extents of the array.
